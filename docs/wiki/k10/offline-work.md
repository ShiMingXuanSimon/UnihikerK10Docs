# 1.3 脱机工作和供电

## 脱机工作

-   在Mind+中为行空板 K10烧录程序后，程序会存储在板子的Flash中，断电不丢失，因此当重新为K10上电后会运行上次烧录过的程序。

## 供电方式

-   支持通过Type-C口供电，5V
-   支持通过板载的PH2.0电池接口供电，3.0-4.2V，推荐使用3.7V锂电池 或 3节串联1.5V干电池进行供电（干电池满电电压接近1.6V，若使用4节串联干电池有烧坏风险）
-   支持通过金手指供电
-   支持通过扩展板供电

> 说明：  
> 出于安全考虑，行空板 K10 未集成电池充电功能，以避免误接不可充电电池或使用不匹配的充电参数而造成电池损坏，甚至带来安全风险。锂电池可以为 K10 供电，但必须使用与电池规格匹配的外部充电器进行充电。
