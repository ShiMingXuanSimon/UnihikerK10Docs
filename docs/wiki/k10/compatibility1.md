# 1.5 扩展板兼容性说明

## 扩展板兼容性说明

**行空板K10兼容部分micro:bit/掌控的扩展板，使用时K10应插在micro:bit一侧**

**行空板K10不兼容[DFR1136 M10双路电机驱动I/O扩展板](https://www.dfrobot.com.cn/goods-3970.html)，K10在使用此扩展板时，仅能使用扩展板的IO接口和I2C接口，无法使用扩展板的电机驱动、RGB、红外收发等功能。**
