# 2.1 屏幕显示积木

## 图片部分

积木

![](/images/k10/968c3aaddbe0fcfe.png)

说明

用于设置屏幕显示方向，显示方向有4种，数字表示屏幕逆时针旋转的度数，每种显示方向对应着不同的坐标范围。

设置屏幕方向只能在初始化时设置，在其他位置设置不生效。

显示方向及屏幕坐标对应图如下

![](/images/k10/9595372d54856091.png)

积木

![](/images/k10/061d05f96aa00017.png)

说明

显示/关闭摄像头画面。使用这条指令，可以将摄像头画面实时显示在K10屏幕上，或将摄像头画面隐藏。

积木

![](/images/k10/a0288e7973a1d6dd.png)

说明

设置屏幕背景颜色。如果不设置，屏幕的背景颜色则默认为白色。

积木

![](/images/k10/640ac14b9300fe0d.png)

说明

将缓存的内容在屏幕上显示出来。

当使用到显示相关指令时（如 文字、形状、图片），需要使用“显示更新”积木后，才会将内容显示出来。

当使用了"显示摄像头画面“后，所有文字、形状、图片都会跟随摄像头画面实时刷新，可以不使用“显示更新”积木。

清除屏幕相关指令调用后会立即清除画面，可以不使用“显示更新”积木

积木

![](/images/k10/635880d0c905cf9c.png)

说明

立即清除屏幕上显示的图片、文字、线条、图形。

摄像头画面无法被此积木清除，要关闭摄像头画面请使用“关闭摄像头画面”积木

生成的二维码无法被此积木清除，要清除二维码请使用“清除二维码显示”积木

积木

![](/images/k10/ac8e8e4ded7c3068.png)

说明

在指定位置（坐标）显示本地图片，可以通过调节图像尺寸的宽和高，设置图片在k10屏幕上的显示大小。

图片尺寸必须在240x320像素以内，过大会造成异常不稳定问题。

若图片加载过多，会超出K10的存储上限，烧录时会报错提示“没有足够的内存”。K10共有16MB的代码存储空间，根据代码的复杂程度不同，会影响可缓存照片的空间大小。

本地加载的图片不支持透明背景的图片，若要显示透明背景图片请通过TF卡加载。

积木

![](/images/k10/ece8e549c0bfee1e.png)

说明

在指定位置（坐标）显示TF内存卡中的图片，支持显示png、jpg和bmp格式图片。

图片尺寸必须在240x320像素以内，过大会造成异常不稳定问题。

此积木可显示透明底的图片。

bmp只支持16位颜色位深的图片，此格式主要用于显示K10拍摄的图片，推荐使用png或jpg格式。

不可通过直接修改后缀名的方式修改图片格式，否则可能会造成显示异常。

积木

![](/images/k10/ca9a99344f5c932e.png)

说明

保存摄像头当前拍摄到的画面并存储在TF卡中。

拍照开始瞬间板子右上角指示灯会亮起，拍照开始建议保持画面静止0.5S，这0.5S内会感觉到明显的屏幕画面卡顿，此时系统正在缓存拍摄到的图片，0.5S后缓存完毕即可自由移动镜头，此时系统会逐步将缓存的图片写到TF卡中。直到右上角指示灯熄灭，表示图片已经成功保存到TF卡中，可以开始下一张图片的拍摄。

使用K10拍照存图时，仅支持存储为bmp格式。对应显示K10拍摄的照片时也仅支持bmp格式。

## 文字部分

积木

![](/images/k10/9f24846e3d498ff2.png)

说明

在K10屏幕上的第一行最左侧开始显示指定颜色的文字。

K10在竖屏时，一共支持13行文字显示。

此指令可快速的完成文字显示，如果需要调节位置请使用可设置坐标的文字显示指令。

此指令会强制执行自动清除操作，有关自动清除的作用请看下一个积木。

积木

![](/images/k10/5020cc322349e7c3.png)

说明

清除指定行上的文字显示。

积木

![](/images/k10/b85b8d57b973d83f.png)

说明

在指定位置（坐标）显示文字，字体大小指汉字字体所占像素，有两种选择24x24和16x16。

一次性最多填入256个汉字，或512个字母。

换行字数表示会根据设定的文字字数，自动换行。在计算换行字数时，中文、英文字母、标点都会被算作一个字数。最大支持换行字数为49，设置为50时默认不换行。

是否自动清除表示是否要先将之前的文字清除重新显示新的文字。开启自动清除后，会自动将坐标后的内容全部清除为背景色，包括已经显示的文字、线条、图片。具体用法请查看下方示例。

当在图片上显示文字时，要将自动清除关闭，使用不断刷新图片的方式来覆盖旧内容

积木

![](/images/k10/edda01115a3af8f5.png)

在屏幕指定位置（坐标）显示指定颜色的点，点的大小不可修改。

积木

![](/images/k10/32a5c703241a085f.png)

说明

设置线条和边框的宽度，单位为像素。

若不调用此积木，则默认线宽/边框宽为1

积木

![](/images/k10/cb2635f90bf81720.png)

说明

根据起点坐标（X1，Y1），终点坐标（X2，Y2）绘制指定颜色的线段。

积木

![](/images/k10/661bd582e4e86c78.png)

说明

根据圆心坐标（X，Y），绘制指定半径的圆。同时，还可以设置圆是否为实心（填充/不填充）、边框和填充颜色。

积木

![](/images/k10/7c1c0549848d51e3.png)

说明

在指定位置（坐标）绘制以矩形左上角为起点的矩形。可以设置矩形的宽和高、边框颜色和填充颜色。
