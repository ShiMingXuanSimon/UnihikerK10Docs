# 2.3 LED控制积木

## RGB LED控制

主控板背面下方有三颗RGB LED灯，使用序号来指定要控制的RGB LED灯。序号和RGB LED灯的位置如下图所示。

![](/images/k10/cd24f1c5cbec0379.png)

积木

![](/images/k10/7f52e22a46333b9e.png)

说明

用于控制指定灯号的RGB LED灯显示指定颜色。

积木

![](/images/k10/70e67b810173c600.png)

说明

用于关闭指定灯号的RGB LED灯，即控制指定灯熄灭。

积木

![](/images/k10/dd638c59e580e969.png)

说明

使用光的三原色（红绿蓝）混色原理，设置RGB LED灯的颜色。

积木

![](/images/k10/87aa19b2b69ee8d5.png)

说明

设置RGB LED灯的亮度，可选择亮度为0-9，共10档，其中0为熄灭状态。

设置亮度后，再次调用显示指令才能使设置的亮度生效。

积木

![](/images/k10/eb91bc1dbe2c10bb.png)

说明

读取RGB LED灯当前的亮度，数据范围为0-9，其中0为熄灭状态。
