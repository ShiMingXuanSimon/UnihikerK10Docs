# 2.4 音频录放积木

## 音频录放

积木

![](/images/k10/87854ef2b74b76ea.png)

说明

后台播放内置音乐。

积木

![](/images/k10/21df2d21e2932dd4.png)

说明

停止播内置放音乐。

这条指令只能用于停止播放内置音乐。

积木

![](/images/k10/311186a96656fb0c.png)

说明

播放指定音调的音符声音，可以设置播放的节拍数。

积木

![](/images/k10/ff1bf7e1edc46567.png)

说明

在后台播放TF存储卡内的指定音频文件，目前只支持wav格式的双声道立体声音频，否则会有杂音或播放加速的问题，可使用推荐的工具进行格式转换[点击跳转](/wiki/k10/FAQ#%E9%9F%B3%E9%A2%91%E7%B1%BB%E9%97%AE%E9%A2%98)。

积木

![](/images/k10/2b6dbc41af2b8fff.png)

说明

停止播放TF储存卡音频。

积木

![](/images/k10/33e0f1b62b181c13.png)

说明

录制指定长时间的音频，命名并保存在TF储存卡中，保存音频格式为wav。

录音过程中，右上角指示灯会亮起

-   按下A按钮，后台播放音乐”BIRTHDAY“；按下B按钮，播放音符 音调”一闪一闪亮晶晶（1155661）

**注意：**“停止播放内置音乐”指令，只能用于停止内置音乐，无法停止音符，这个项目中，按下B按钮，能停止播放内置音乐“BIRTHDAY”，但是按下A按钮，不能停止播放音符“1155665”，会出现音符和内置音频同时播放的情况。

![](/images/k10/6bdcf731582cfd61.png)

-   为了避免出现同时播放内置音频和音符的情况，我们将播放的内容都放到“循环执行”指令中，在按键中断下，只需要改变标志位变量的值即可。这样修改后，内置音频和音符不会出现同时播放的情况，并且只有当一种音乐播放完成后，你按下按钮才能控制另一种音乐播放。

![](/images/k10/dc32a09ae2885ad9.png)

-   按下A按钮，录制3秒音频并存储到TF卡中；按下B按钮，播放录制好的音频。

![](/images/k10/a5a15f131a3115d8.png)
