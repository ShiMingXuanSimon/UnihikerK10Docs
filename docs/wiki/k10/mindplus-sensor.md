# 2.2 板载传感器积木

## 板载传感器

积木

![](/images/k10/6f18e70be77faf7f.png)

说明

板载按键A/B按下/松开时，触发中断。

中断中不可使用无限循环、长时间延时等积木，为保证系统的稳定性，中断代码应尽可能简短。

积木

![](/images/k10/29bd76f620a8d58f.png)

说明

用来检测板载按键A/B的状态（按下/松开）。

启用摄像头/AI功能后，建议使用按键中断的方式来判断按键按下。

积木

![](/images/k10/eef93b58cc5fbda9.png)

说明

检测主控板当前姿态为向前倾斜/向后倾斜/向左倾斜/向右倾斜/屏幕朝上/屏幕朝下，共6种姿态的检测。

积木

![](/images/k10/ffc4ea2fdd208949.png)

说明

通过板载传感器AHT20，读取当前环境的温度（单位：摄氏度或华氏度）或湿度数据（相对湿度）。

积木

![](/images/k10/54bfaaac0c4e8896.png)

说明

读取板载光线传感器的环境光，单位Lux。

积木

![](/images/k10/0f93d24a491fb7e0.png)

说明

读取板载加速度传感器（X方向、Y方向、Z方向或强度）的数值，单位为毫重力（m-g）。沿着下图箭头方向，竖直（重力方向）放置板子，读取到的数值是正的，且与重力加速度（mm/s2）类似。![](/images/k10/9b025159295dd812.png)
